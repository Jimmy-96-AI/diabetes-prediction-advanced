# 🩺 Diabetes Risk Prediction using Machine Learning

Predict whether a person is at risk of diabetes based on health parameters like Glucose, Blood Pressure, BMI, Insulin, Age and more.

## 🚀 Features
- Data Cleaning & Exploratory Data Analysis (EDA)
- Machine Learning Model Training & Evaluation
- Accuracy Comparison of Multiple Models
- Interactive Diabetes Risk Prediction

## 🛠️ Tech Stack
- Python
- Pandas, NumPy
- Matplotlib, Seaborn
- Scikit-learn
- Jupyter Notebook

## 📊 Dataset
PIMA Indians Diabetes Dataset
- Pregnancies, Glucose, BloodPressure, SkinThickness, Insulin, BMI, DiabetesPedigreeFunction, Age, Outcome
